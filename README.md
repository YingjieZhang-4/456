# Whitsunday in sound
1. Project Overview

Whitsunday in Sound is a music programming project created using Python and TunePad. The work expresses the feelings during a Whitsunday trip through six consecutive emotional stages, including anticipation, excitement, awe, disappointment, happiness and calmness.

The project allows different emotions to gradually change in the music by adjusting pitch, rhythm, note length, dynamics and instrument combinations. The final work consists of seven audio tracks and organizes the music using programming concepts such as functions, loops, lists and conditionals.

2. Tools and Technologies

Python: Writing music programs.

TunePad: Write, play and test each audio track.

GitHub: Save and display the source code of the project.

3. Project Structure

The project consists of seven audio tracks, each of which undertakes different musical functions.

Electric Bass: Provides the foundation of bass and rhythm.

: Organize drumbeat rhythms using lists, loops and functions.

Main Piano: Playing the main melody and harmony, it is the main part of music.

Guitar: Use a few single notes as embellishments to add layers to the music.

Supporting Harmony: Add supporting harmonies during certain emotional phases.

Shaker: Adds additional rhythm layers to some paragraphs.

Additional Melody: Add an auxiliary melody to a specific section.

The seven audio tracks work in coordination, presenting the emotional changes during the journey through different sound combinations.

4. Programming Features

playNote() : Controls the playback of notes.

rest() : Schedule pauses.

phrase() : Organizes piano melody and harmony through parameters.

drum_bar() : Arrange the rhythm based on the position of the drum beats.

for loops: Handle sequences of notes and drumbeats.

Lists: Store notes, durations and drumbeat positions.

Conditionals: Determine whether to play notes based on conditions.

rewind() and moveTo() : Control the position where the music plays.

5. How to Run

Open TunePad: https://tunepad.com/

Create a new music project.

Create seven corresponding audio tracks based on the file names in the tracks folder in the warehouse.

Copy the code in each.py file to the code editor corresponding to the TunePad track.

Make sure the audio track uses the correct instruments and set the project tempo to 120 BPM and the time signature to 4/4.

Run all the audio tracks and play the complete music.

Note: These codes use the music programming functionality provided by TunePad and need to be run in the TunePad environment rather than directly executed using a regular python interpreter.
